C Programming: Star Pattern

Using nested loops and conditional statements to print a symmetric star pattern.

Problem

Write a C program to print the following star pattern using loops:

* * * * *
  * * *
    *
  * * *
* * * * *

C Code

#include <stdio.h>

int main()
{
    int i, j, s, n;

    for(i = 1; i <= 5; i++)
    {
        if(i <= 3)
        {
            s = i - 1;
            n = 7 - 2 * i;
        }
        else
        {
            s = 5 - i;
            n = 2 * i - 5;
        }

        for(j = 1; j <= s; j++)
        {
            printf("  ");
        }

        for(j = 1; j <= n; j++)
        {
            printf("* ");
        }

        printf("\n");
    }

    return 0;
}

How the Logic Works

  • The outer loop runs five times, so the pattern has five rows.
  • s determines how many pairs of leading spaces are printed.
  • n determines how many stars are printed in each row.
  • For rows 1–3, the number of stars decreases: 5, 3, 1.
  • For rows 4–5, the number of stars increases: 3, 5.
  • The two inner loops print the leading spaces and then the stars.

The program uses nested for loops and an if-else condition.
